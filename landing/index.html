semantic-stack a turnkey semantic web stack

Every service in the stack, with a live reachability check. Green means the port answers from your browser. Ports are the compose defaults; if you changed them in .env, adjust the links.

Triple stores

Apache Jena Fuseki

Primary store. SPARQL Query and Update, Graph Store Protocol, SHACL and text index. Login admin / admin. Holds data/sample after make load.

query UI/ds/sparql/ds/update

QLever

Profile qlever (make qlever-up). Very fast engine for large, read-mostly graphs; indexed once. Serves the Olympics demo (1.8M triples).

QLever UIraw SPARQL

Oxigraph

Profile oxigraph (make oxigraph-up). Lightweight Rust store, zero setup, built-in YASGUI.

/query/update

GraphDB

Profile graphdb (make graphdb-up). Ontotext GraphDB Free.

Query, browse, visualise

Trifid

Linked Data frontend over Fuseki: dereferenceable IRIs (try /service/fuseki after make load), YASGUI console, Graph Explorer, CORS proxy.

SPARQL consoleGraph Explorer/query proxy

Blueprint

Knowledge-graph browser. Needs a Blueprint configuration graph in the store before it shows anything.

WebVOWL

OWL ontology visualisation with the OWL2VOWL converter. Try FOAF, or upload data/sample/semantic-stack-vocab.ttl.

RDF4J Workbench

Repository manager. Add a "SPARQL endpoint proxy" repository pointing at http://qlever:7001 or http://fuseki:3030/ds/sparql.

Comunica

Federated SPARQL endpoint at /sparql. Add QLever or Oxigraph to its sources with COMUNICA_SOURCES in .env.

sparql-proxy

Cache, job queue and concurrency limit in front of Fuseki (or another store via SPARQL_PROXY_BACKEND); rejects SPARQL Update. The read-only, CORS-enabled endpoint to hand to browser tools.

/sparqladmin dashboard

Sparklis

Build SPARQL by clicking through the data in plain English. Opens on Fuseki via sparql-proxy.

full UI with endpoint picker

Skosmos

SKOS vocabulary browser and REST API over Fuseki. Shows the sample thesaurus of tool categories after make load.

stack vocabularyREST

Sparnatural

Visual query builder driven by a SHACL configuration of the sample data (sparnatural/config.ttl). Queries go to sparql-proxy.

Graph Explorer

AWS Graph Explorer over Fuseki: click through instances and relations. Profile graph-explorer.

Prez

Linked Data API over Fuseki with content negotiation by profile and OGC API Features. Profile prez; UI on :8001.

OpenAPI/object?uri=...

grlc

The .rq files in grlc/queries as a Swagger-documented REST API over Fuseki. Profile grlc.

/services

RPT

RDF Processing Toolkit: SPARQL endpoint with YASGUI, GraphQL and a Linked Data viewer proxying Fuseki. Profile rpt.

YASGUIGraphQL

OpenRefine

Ontop

Virtual knowledge graph over Postgres. Optional: make ontop-up, then query /sparql.

JupyterLab

YASGUI/sparql.anything

Validate against shapes with readable reports, document shapes as HTML and UML, generate shapes from data, OWL to SHACL, SHACL rules.

validatedocumentgenerate

SHACL validation over HTTP: POST /validate with data_graph and shapes_graph. OpenAPI docs at /docs/swagger.

ITB SHACL validator

European Commission test-bed validator: web form, REST and SOAP over data/sample/shapes.ttl. Profile validation.

Swagger

pyLODE server

Ontology documentation by URL. Profile docs. Try the sample vocabulary.

LinkedPipes ETL

Visual Linked Data ETL pipelines. Profile lp-etl (four containers).

CLI tools

RMLMapper, YARRRML, SDM-RDFizer, rudof (ShEx/SHACL), EYE (N3), ROBOT (OWL), Nemo (Datalog), WIDOCO, RPT, jelly-cli, pySHACL, LinkML generators via docker compose --profile tools run --rm <service>. See data/README.md. Browse ./data.

Agents, LLMs, observability

MCP servers

Profile mcp: sparql-mcp (SPARQL 1.1 over Fuseki, SSE), rudof-mcp (ShEx/SHACL/SPARQL, streamable HTTP) and open-ontologies (ontology engineering). Register them with claude mcp add; see the README.

Flexible GraphRAG

LLM knowledge-graph extraction into Fuseki + Qdrant with hybrid search, chat UI and MCP (:3001). Profile graphrag; needs an LLM key or the ollama profile.

API docsQdrant

Ollama

Local LLM with an OpenAI-compatible API. Profile ollama; pull a model with docker compose --profile ollama exec ollama ollama pull qwen3:8b.

Grafana

SPARQL datasource over Fuseki plus Prometheus (:9091) scraping the SPARQL exporter. Profile observability. Login admin / admin.

First steps

make up             # start the default stack (Fuseki primary)
make load           # load data/sample into Fuseki
make smoke          # check every service answers
make qlever-up      # optional: add QLever + UI with the Olympics demo (indexes on first run)
make oxigraph-up    # optional: add Oxigraph
make profile P=prez # optional: any other profile (virtuoso, geosparql, prez, grlc, graph-explorer, docs, rpt,
                    #           lp-etl, validation, observability, mcp, graphrag, ollama, solid)
Container-to-container URLs use service names (http://fuseki:3030/ds/sparql). Browser URLs use localhost. Blueprint and the QLever UI are browser apps, so they are configured with localhost URLs. Grey dots are services whose profile is not running.
