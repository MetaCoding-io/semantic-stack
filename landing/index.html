semantic-stack a turnkey semantic web stack

Every service in the stack, with a live reachability check. Green means the port answers from your browser. Ports are the compose defaults; if you changed them in .env, adjust the links.

Triple stores

QLever

Primary store of the default stack. Very fast, read-mostly, needs the one-time qlever-index step. Serves the Olympics demo data.

QLever UIraw SPARQL

Apache Jena Fuseki

General-purpose store with SPARQL Update, Graph Store Protocol, SHACL and text index. Login admin / admin. Holds data/sample after make load.

query UI/ds/sparql/ds/update

Oxigraph

Alternative primary store, zero setup. Only runs with compose.oxigraph.yml.

/query/update

GraphDB

Ontotext GraphDB Free. Optional: make graphdb-up.

Query, browse, visualise

Trifid

Linked Data frontend over the primary store: dereferenceable IRIs, YASGUI console, Graph Explorer, CORS proxy.

SPARQL consoleGraph Explorer/query proxy

Blueprint

Knowledge-graph browser. Needs a Blueprint configuration graph in the store before it shows anything.

WebVOWL

OWL ontology visualisation with the OWL2VOWL converter. Try FOAF, or upload data/sample/semantic-stack-vocab.ttl.

RDF4J Workbench

Repository manager. Add a "SPARQL endpoint proxy" repository pointing at http://qlever:7001 or http://fuseki:3030/ds/sparql.

Comunica

Federated SPARQL endpoint over every store in the stack at /sparql.

sparql-proxy

Cache, job queue and concurrency limit in front of the primary store; rejects SPARQL Update. The read-only, CORS-enabled endpoint to hand to browser tools.

/sparqladmin dashboard

Sparklis

Build SPARQL by clicking through the data in plain English. Opens on the primary store via sparql-proxy.

full UI with endpoint picker

Skosmos

SKOS vocabulary browser and REST API over Fuseki. Shows the sample thesaurus of tool categories after make load.

stack vocabularyREST

Transform and model

OpenRefine

Interactive data cleaning. ./data is mounted read-only at /import.

Ontop

Virtual knowledge graph over Postgres. Optional: make ontop-up, then query /sparql.

JupyterLab

rdflib, pySHACL, LinkML, pyLODE, SPARQLWrapper. Optional: make jupyter-up.

SPARQL Anything

Query CSV, JSON, XML, HTML or spreadsheets as RDF with no mapping. ./data is visible as /data; try data/queries/30-sparql-anything-csv.rq.

YASGUI/sparql.anything

SHACL Play

Validate against shapes with readable reports, document shapes as HTML and UML, generate shapes from data, OWL to SHACL, SHACL rules.

validatedocumentgenerate

pySHACL service

SHACL validation over HTTP: POST /validate with data_graph and shapes_graph. OpenAPI docs at /docs/swagger.

CLI tools

RMLMapper, YARRRML, SDM-RDFizer, rudof (ShEx/SHACL), EYE (N3 reasoning), jelly-cli, pySHACL, LinkML generators via docker compose --profile tools run --rm <service>. See data/README.md.

First steps

make qlever-index   # one-time: build the QLever index (Olympics demo, ~1.8M triples)
make up             # start everything
make load           # load data/sample into Fuseki
make smoke          # check every service answers
Container-to-container URLs use service names (http://fuseki:3030/ds/sparql). Browser URLs use localhost. Blueprint and the QLever UI are browser apps, so they are configured with localhost URLs.
