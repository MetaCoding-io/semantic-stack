semantic-stack a turnkey semantic web stack

Every service in the stack, with a live reachability check. Green means the port answers from your browser. Ports are the compose defaults; if you changed them in .env, adjust the links.

Triple stores

Apache Jena Fuseki

Primary store. SPARQL Query and Update, Graph Store Protocol, SHACL and text index. Login admin / admin. Holds data/sample after make load.

query UI/ds/sparql/ds/update

QLever

Profile qlever (make qlever-up). Very fast engine for large, read-mostly graphs; indexed once. Serves the Olympics demo (1.8M triples).

QLever UIraw SPARQL

Oxigraph

Profile oxigraph (make oxigraph-up). Lightweight Rust store, zero setup, built-in YASGUI.

/query/update

GraphDB

Profile graphdb (make graphdb-up). Ontotext GraphDB Free.

Query, browse, visualise

Trifid

Linked Data frontend over Fuseki: dereferenceable IRIs (try /service/fuseki after make load), YASGUI console, Graph Explorer, CORS proxy.

SPARQL consoleGraph Explorer/query proxy

Blueprint

Knowledge-graph browser. Needs a Blueprint configuration graph in the store before it shows anything.

WebVOWL

OWL ontology visualisation with the OWL2VOWL converter. Try FOAF, or upload data/sample/semantic-stack-vocab.ttl.

RDF4J Workbench

Repository manager. Add a "SPARQL endpoint proxy" repository pointing at http://qlever:7001 or http://fuseki:3030/ds/sparql.

Comunica

Federated SPARQL endpoint at /sparql. Add QLever or Oxigraph to its sources with COMUNICA_SOURCES in .env.

Transform and model

OpenRefine

Interactive data cleaning. ./data is mounted read-only at /import.

Ontop

Virtual knowledge graph over Postgres. Optional: make ontop-up, then query /sparql.

JupyterLab

rdflib, pySHACL, LinkML, pyLODE, SPARQLWrapper. Optional: make jupyter-up.

CLI tools

RMLMapper, YARRRML, pySHACL, LinkML generators via docker compose --profile tools run --rm <service>. See data/README.md.

First steps

make up             # start the default stack (Fuseki primary)
make load           # load data/sample into Fuseki
make smoke          # check every service answers
make qlever-up      # optional: add QLever + UI with the Olympics demo (indexes on first run)
make oxigraph-up    # optional: add Oxigraph
Container-to-container URLs use service names (http://fuseki:3030/ds/sparql). Browser URLs use localhost. Blueprint and the QLever UI are browser apps, so they are configured with localhost URLs. Grey dots are services whose profile is not running.
